# CTRLtek.Live — MVP Backlog

## Product model validated 2026-09-24

CTRLtek.Live is an open electronic-artist ecosystem built around four actions: **CREATE · COLLABORATE · RELEASE · PERFORM**.

### P0 — Launch foundation
- [ ] Reframe FR/EN homepage around CREATE · COLLABORATE · RELEASE · PERFORM.
- [ ] Make **Join Free** the primary CTA.
- [ ] Remove selective-entry messaging from community registration.
- [ ] Replace legacy navigation with Discover / Collab / Services / Records / Live / About.
- [ ] Define member account/authentication architecture.
- [ ] Define artist profile data model.

### P1 — MVP
- [ ] Community: account, artist profile, artist directory.
- [ ] Collab Engine Lite: project workspace, project chat, files/stems, versions, feedback.
- [ ] Collective billing: Free, Founding Member €4.90/month (first 50), regular €9.90/month.
- [ ] Creative Services storefront and order flow.
- [ ] Records: demo submission; A&R handled manually/Trello initially.
- [ ] Records: 60% artist / 40% label deal model; artist retains master ownership. Contract wording requires legal review.
- [ ] Live: performer profiles and booking request form.
- [ ] Booking: 15% commission on opportunities generated by CTRLtek.Live.
- [ ] Knowledge Base integration; Notion can remain the operational source for MVP.

## MVP validation targets
- 50 registered members
- 10 Founding Members
- 5 active collaborations
- 5 Creative Services orders
- 10 A&R demos
- 1 CTRLtek.Live Records release
- 1 booking opportunity

## Product principles
1. Anyone can join the community for free.
2. Collective sells collaboration infrastructure, not access to artistic opportunities.
3. Buying services never affects A&R or booking selection.
4. Records and booking remain accessible to Free members.
5. One music project = one collaboration workspace.
6. Use Trello, Notion, external distribution and manual operations until volume justifies automation.
